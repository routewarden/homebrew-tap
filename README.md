# RouteWarden Homebrew Tap 🍺

Official Homebrew tap for [RouteWarden](https://routewarden.github.io) command-line tools.

## Installation

Add this tap and install `rwarden`:

```bash
brew install routewarden/tap/rwarden
```

Or tap explicitly:

```bash
brew tap routewarden/tap
brew install rwarden
```

## Update & Upgrade

To update the tap and upgrade `rwarden` to the latest release:

```bash
brew update
brew upgrade rwarden
```

## Verify Installation

```bash
rwarden version
rwarden --help
```
